# Rubrics

`narrative-quality-v1.md` definiuje osiem obowiązkowych wymiarów oceny, zamknięty katalog
reason codes, severity oraz przykłady dla strict `JUDGE`. Sędzia nie zwraca wiążącego
overall verdict ani persistowalnego free-form rationale; kod publikuje tylko przy ośmiu
`PASS` i zerze findings.

Rubryka, dataset, prompt, schemas i publication policy są wersjonowane razem. Zmiana
semantyki wymaga nowej wersji i nowego przechodzącego baseline.
